第三方程序接入（手动复制 DLL）

插件 DLL 就在本程序的 plugins\ 文件夹里，复制到对应宿主的插件目录、重启宿主即可：
· TrafficMonitor → 复制 trafficmonitor_hr_plugin.dll 到 plugins\， 重启后在 设置→插件 里把“心率”加进显示项
· MSI Afterburner → 复制 afterburner_hr_plugin.dll 到 Plugins\Monitoring\， 重启后在 设置→监控 里启用插件，再把“心率”加进 OSD 显示项
· 装过旧名 DLL（HeartRate.dll / hr_plugin.dll）的先删掉旧文件，否则会出现重复的“心率”项
